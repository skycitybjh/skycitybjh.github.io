■ 홈페이지 내용 업데이트 방법 (논문·뉴스·구성원·과제)

index.html을 메모장(또는 아무 텍스트 편집기)으로 열면 파일 맨 위에
"★ 내용 데이터" 라고 표시된 구역이 있습니다. 홈페이지의 모든 목록은
이 데이터를 읽어 자동으로 그려지므로, **이 구역만 수정하면 됩니다.**
번호 매기기, 논문 수 통계(첫 화면의 "32 SCI/E PAPERS" 등), 탭의 (32) 표시가
모두 자동으로 갱신됩니다.

──────────────────────────────────────────────
1) 새 국제논문 추가  →  pubsInt: [  바로 아래에 한 덩어리 추가
──────────────────────────────────────────────
 {title:"논문 제목", tag:"교신저자", note:"",
  authors:"공저자1, 공저자2, <b>J. Bae*</b>", journal:"저널명 권(호), 페이지 (2026) · Q1 · IF 0.0"},

 · tag는 "주저자" / "교신저자" / "단독저자" / "" (공동저자) 중 하나
 · 게재확정(아직 미출판)이면 note:"IN PRESS"
 · 본인 이름은 <b>J. Bae</b> 처럼 <b> </b>로 감싸면 굵게 표시, 교신저자는 이름 뒤 *
 · 최신순 유지: 항상 배열의 맨 위(대괄호 [ 바로 다음)에 추가
 · 국내논문은 pubsDom, 저서는 books에 같은 방식

──────────────────────────────────────────────
2) 새 뉴스 추가  →  news: [  바로 아래에 추가
──────────────────────────────────────────────
 {date:"2026.09", link:"https://기사주소", photo:"news-photo1",
  ko:{title:"국문 제목", desc:"국문 한 줄 설명."},
  en:{title:"English title", desc:"English one-line description."}},

 · link에 기사(신문·학회 소식 등) 주소를 넣으면 제목이 클릭 가능한 링크(↗)가 됩니다. 없으면 link:""
 · photo:"파일명"을 적고 images\news\파일명.jpg 로 사진을 넣으면 뉴스 아래 표시됩니다. 없으면 photo:""

──────────────────────────────────────────────
2-1) 게재 저널 카드  →  journals 배열
──────────────────────────────────────────────
 {key:"es", abbr:"ES", name:"Engineering Structures", meta:"ELSEVIER · Q1",
  url:"https://www.sciencedirect.com/journal/engineering-structures"},

 · Publications 하단 'Journals We Publish In' 카드로 표시되고, 클릭하면 url로 이동합니다
 · 표지 이미지는 images\journals\key.jpg (없으면 abbr 약어로 표시)

──────────────────────────────────────────────
3) 구성원 추가/변경  →  people 배열
──────────────────────────────────────────────
 {initial:"홍", photo:"gildong-hong", name:"홍길동 GilDong Hong", role:"M.S. RESEARCHER",
  ko:"연구 주제", en:"Research topic"},

 · photo는 사진 파일명 (images\people\gildong-hong.jpg 로 저장 — 사진_넣는_방법.txt 참고)
 · 졸업하면 people에서 지우고 alumni 배열로 옮기면 됩니다

──────────────────────────────────────────────
4) 과제 추가  →  projects 배열 (맨 위 = 목록 맨 위)
──────────────────────────────────────────────
 {id:"PJ.10", badge:"ONGOING", hot:true, photo:"pj10",
  ko:{title:"과제명", meta:"발주처 · 기간 · 역할", desc:"설명."},
  en:{title:"English title", meta:"", desc:"English description."}},

 · hot:true면 왼쪽에 녹색 강조선 · badge는 "ONGOING"/"NRF"/"" 등
 · 과제 사진은 images\projects\pj10.jpg

──────────────────────────────────────────────
주의사항
──────────────────────────────────────────────
 · 각 항목 끝의 쉼표(,)와 따옴표 짝을 지키세요 — 하나라도 깨지면
   목록이 이전 상태(파일에 남아있는 예비 내용)로 표시됩니다.
   수정 후 index.html을 브라우저로 열어 정상 표시되는지 꼭 확인하세요.
 · 문장 안에 큰따옴표(")를 쓰려면 작은따옴표(')나 「 」를 사용하세요.
 · 더 크게 바뀌는 내용(교수 경력·수상, 연구분야 소개 등)은 파일 본문에
   있으므로, 그때는 Claude에게 "OO 수정해줘"라고 요청하는 게 빠릅니다.
